icepdf @version@

Pure-Java PDF rendering and viewing: render, view, annotate, fill, redact and sign PDF documents. Apache License 2.0.

What's in this bundle

libs/ The icepdf jars (core, fonts, the Swing viewer and the JavaFX viewer) and every third-party jar they need at run time, except JavaFX itself.
libs-source/ Source jars for icepdf core and both viewers, for attaching to your IDE.
licenses/ The Apache License 2.0 and the licences of the bundled third-party libraries and adapted code.
NOTICE Attribution notices for the code and libraries icepdf includes.
maven2/ The published POMs for core, the Swing viewer and the JavaFX viewer.

Run a viewer

The JavaFX viewer needs Java 17 or later and JavaFX 22 or later, which isn't in this bundle because it's per platform. Download the JavaFX SDK for your platform from gluonhq.com, then, from this folder:

java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls \
     -cp "libs/*" org.icepdf.fx.ri.app.ViewerApp [file.pdf]

The Swing viewer needs Java 11 or later and nothing else:

java -jar libs/icepdf-viewer-@version@.jar

Use the library

icepdf is on Maven Central under com.github.pcorless.icepdf:

<dependency>
  <groupId>com.github.pcorless.icepdf</groupId>
  <artifactId>icepdf-core</artifactId>
  <version>@version@</version>
</dependency>

Add icepdf-viewer for the Swing viewer or icepdf-viewer-fx for the JavaFX viewer. For Gradle: implementation 'com.github.pcorless.icepdf:icepdf-core:@version@'.

Source, issues and building

The source is on GitHub at github.com/pcorless/icepdf. Ask questions in Discussions and report bugs in the issue tracker; a sample PDF gets a problem fixed fastest.

To build from source, clone the repository and run ./gradlew assemble or mvn package. The examples are built from the repository too. See Building from source on the wiki for details.
